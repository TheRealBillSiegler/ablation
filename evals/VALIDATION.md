## Edit applied (2026-08-06, owner-approved)

Tier-3 section compressed to one paragraph: outcome + frame-approval gate + template pointer. Removed text below, verbatim, per the skill's paste-back rule.

```text
On invocation with a target component, execute:
1. **Gather:** the component's verbatim text, its stated purpose or violation history, and the steering context it lives in.
2. **Draft the frame:** the intended effect as a checkable criterion, plus 3–6 realistic probe tasks the component should influence (never quizzes about the rule). Present criterion + probes to the human for approval — the frame is a judgment call; everything after it is mechanical.
3. **Launch** the bundled workflow template ([scripts/tier3-arms.workflow.js](https://github.com/TheRealBillSiegler/ablation/blob/main/skills/ablation/scripts/tier3-arms.workflow.js)) with the approved frame: it spawns control and ablated arms (steering delivered inline per arm — the live file is never touched), ≥3 reps per probe per arm, then blind graders who see paired outputs under neutral labels with arm identity withheld, judging only the pre-registered criterion.
4. **Tally mechanically** (the template does this in code, not judgment): LOAD-BEARING = effect present in control, absent/degraded in ≥2/3 ablated reps of any probe. CEREMONY = no reproducible delta. HARMFUL = ablated better on ≥2/3 reps. Else UNRESOLVED — reported as such, never rounded.
5. **Report:** stamped verdict + per-probe evidence + the removed text verbatim + the recommended action.

Cost honesty: a default run (3 probes × 3 reps × 2 arms + graders) spawns ~25–30 agents. Size probes accordingly; that cost is why tiers 1–2 exist. Environments without a workflow tool degrade to sequential agent spawns — slower, same procedure.
```

### Per pillar

- **ML-ablation provenance — MIXED.** The canonical definition ("determine the contribution of a component… by removing the component, and then analyzing the resultant performance") matches the design exactly; prompt-component ablation is current published practice (arXiv 2507.02938 removes one prompt component at a time and measures the delta); the term is generalized to prompt components in reference glossaries. Bound: ablation is a de facto community norm, not a formal checklist item — the NeurIPS Paper Checklist, NeurIPS 2025 reviewer guidelines, and ACL/ARR checklist contain zero occurrences of the word. Never claim checklist status.
- **Experimental design — MIXED.** Pre-registration (Nosek et al., PNAS 2018), assessor blinding rationale (PLOS Medicine), and UNRESOLVED-as-designed-outcome (three-outcome pilot-trial literature) are each supported. Bounds: every fetched source discussing minimum-n floors sets them well above 3; the any-probe rule is uncorrected multiple looks; the 2/3 thresholds are fixed constants with no error-rate derivation ("whenever a pilot trial progression criteria is specified… it is mathematically equivalent to a hypothesis test"); the strongest available defense — exploratory/screening framing, not confirmatory — is one the skill never states.
- **LLM-as-judge — MIXED.** Judging one isolated pre-registered criterion matches Anthropic eval guidance verbatim; enum verdicts over numeric scores match OpenAI guidance. Bounds: the field standard for position bias is querying the judge twice per pair in both orders and counting only order-consistent verdicts — single-query parity alternation is a weaker, unvalidated substitute; verbosity bias is unmitigated; no human-calibration step; literature is silent on the both-arms-same-family-as-judge configuration this template defaults to.

### Confirmed load-bearing defects (BOUNDS; orchestrator-verified against the script)

1. **Grader-regime instability.** If graders force-choose X/Y (never both/neither), ctrlPass+ablPass=n by construction: every probe lands degraded or harmful, CEREMONY is structurally unreachable, and a coin-flip grader returns false LOAD-BEARING 12.5% of the time at 3 probes. If graders answer "both" liberally (the regime the recursive run was in), any-probe-degraded becomes a genuine disjunction. Nothing measures or reports which regime a run was in.
2. **Uncalibrated instrument.** No positive control (known load-bearing component recovered as LOAD-BEARING) and no placebo control (irrelevant line) have ever been run; the only execution record is the recursive self-run, on the since-superseded args contract. Until both controls are recorded here, tier-3 verdicts are screening signals from an uncalibrated instrument.
3. **Blinding below field standard.** At reps=3 the parity swap gives a 2:1 positional split within each probe; a purely position-biased grader meets the degraded threshold within a probe (cross-probe parity alternation accidentally converts pure position bias into UNRESOLVED — partial, unengineered mitigation).
4. **reps floor not enforced where it matters.** Grader failures are filtered before the tally; a probe can tally at n=1, where ceil(2n/3)=1 makes LOAD-BEARING reachable off a single surviving grader call, while the stamp line prints the requested reps.
5. **CEREMONY band swallows real effects.** At n=3, control 3/3 vs ablated 2/3 (a one-third compliance drop) classifies as no-delta. CEREMONY means "no delta detected at this n," not evidence of absence.
6. **Derived-arm overclaim.** split/join removes every occurrence of the component, not one, and removal leaves structural residue (doubled blanks, orphaned markers) plus a length/position shift — material given measured prompt-format sensitivity (±23% on MMLU from a delimiter choice). "Differ by exactly the component" overclaims.
7. **Criterion leakage.** The anti-quiz gate covers probes only; a criterion that restates the component's surface form un-blinds the grader through output content.
8. **Probe-shopping path.** Re-running after UNRESOLVED with adjusted probes carries no attempt lineage and no fresh-approval requirement; the final stamped report is indistinguishable from a first attempt.

Attacks ruled FAILS: randomization-vocabulary complaint (matched pairs is the stronger control here — every probe receives both conditions); term-misappropriation and reinvention (definition matches, prior art searched, no superior competitor found); unfalsifiable-expiry-premise (the premise is better supported than the skill claims).

### Changes the evidence justifies (applied 2026-08-06, owner-approved)

Template (deterministic, in code): (a) force UNRESOLVED for any probe whose surviving n < 3 and report grader-failure counts; (b) throw when the component occurs more than once in steering; (c) throw when the criterion contains the component verbatim; (d) report per-probe grader verdict mix (both/neither/forced — recoverable from the tally booleans) and force UNRESOLVED when a run contains zero both/neither verdicts (the CEREMONY-unreachable regime); (e) grade each pair twice in both orders, counting only order-consistent verdicts (doubles grade calls ~9→18/run — the field-standard mitigation); (f) collapse whitespace residue after removal; (g) optional attempt-lineage args recorded in the report.

SKILL.md (irreducibly prose): state the exploratory/screening framing and that CEREMONY is weak evidence of absence at default n — delete on CEREMONY only for components without violation history, else raise reps; state that verdicts are uncalibrated until a positive-control and placebo run are recorded here; state that blinding is label-level and criteria must be outcome-shaped, never restatements of the component; recommend a grader from a different family/tier than workers and a human spot-check before CEREMONY authorizes deletion; require fresh frame approval and an attempt number on any re-run after UNRESOLVED; add the Anthropic migration-doc citation for verdict expiry (replacing "no external source").

Process (before next destructive use): run the positive control and placebo control through the template and record both results here.

Deviation from the critic's literal edit (d): implemented as verdict-mix reporting WITHOUT the hard zero-both/neither→UNRESOLVED veto. Rationale: with double-query order-consistency filtering (e) and the tally-level n floor (a) both in place, a run of all-ctrl-only verdicts is the expected signature of a clean strong effect — the veto would misclassify every true LOAD-BEARING result — while the false-LOAD-BEARING path the veto targeted (coin-flip or position-biased graders in the forced-choice regime) is closed upstream: such graders produce order-inconsistent pairs, which drop reps and trip the n floor. CEREMONY remains structurally unreachable without both/neither verdicts, so no CEREMONY guard is needed.

Rejected on its evidence: extracting a shared statistics module — workflow scripts run sandboxed with no filesystem or module access, so the template cannot import; the duplicated block plus its parity assertion is the correct mitigation for a hard runtime constraint, not a smell. Verdict vocabulary is mode-scoped (ORIGINAL-BETTER / REPLACEMENT-BETTER / NO-DIFFERENCE) over an unchanged mode-blind tally; the report adapter is label-parameterized, and pre-substitution run files render identically through a removal-labels fallback (verified against both archived calibration runs). Latent confound found and fixed in the same pass: whitespace normalization was applied only to arm B, so steering that already contained blank-line runs differed between arms by more than the component — both arms are now normalized identically. Test suite extended from math-only to executing the real script body against stub harness functions: eleven refusal cases (reps floor, probe count, component absent, component at two sites, probe or criterion quoting the original OR the rewrite, missing ISO date, alpha out of range, replacement identical to original) plus a valid frame of each mode reaching the first spawn — all passing. Adversarial verification of this hardening (workflow wf_22377a20-853, 2026-08-09; 3 sonnet reviewers — correctness/high, scientific validity/high, documentation/medium — 236k tokens): 12 raw findings, 10 accepted and applied, 2 judged already-handled with the reason recorded. **Three correctness defects, all confirmed by re-derivation:** (1) arm B was spliced with a *string* replacement, so a rewrite containing `$&`, `` $` ``, `$'` or `$$` would silently expand — `$&` re-injects the original component into arm B, and `` $` ``/`$'` splice in unbounded runs of surrounding steering, a worse violation of the one-site invariant than removal mode ever risked (fixed with a function replacer, which inserts literally; the reviewer and I found this one independently); (2) the distinctness gate compared the caller's raw strings while normalization runs *after* the splice, so raw-distinct inputs could normalize to byte-identical arms and burn ~60 agents producing a verdict from a zero-site difference — the gate now compares the texts workers actually receive; (3) `stats.direction`/`pooled.direction` still emitted `better-with`/`better-without` in substitution runs, leaking removal vocabulary into archived data the reports link as source — now mode-scoped like every other named field. **Two scientific bounds accepted as documentation, not code:** substitution's blinding risk is strictly larger than removal's (text-versus-silence is one binary tell; two live wordings each stamp register and structure onto outputs, and only verbatim quoting is mechanically catchable), and substitution's null hypothesis is weaker (a deleted span cannot produce a directional effect, but two live wordings can help *different* probes and cancel — though the existing rules already surface threshold-crossing conflicts as UNRESOLVED rather than as a verdict, which the reviewer's framing understated). **One confound now reported rather than ignored:** a one-site swap controls nothing about length, token count, or structure, so both versions' character and line counts are computed into the run data and rendered in the report. **Documentation fixes:** an uncalibrated run no longer renders with clean "good" styling (it renders hedged, with the warning promoted into the banner); the rules note now lists only the vocabulary the report actually uses instead of both modes'; a p-value rounding to zero renders "under 0.1%" rather than "0%", which read as impossible. Judged already-handled: the screening thresholds not being re-derived for substitution (that is exactly what the calibration debt covers), and the sign-test interaction concern (partially valid, documented as a bound). Test suite extended with the two new refusal cases and a direct assertion that `$&` splices literally; archived removal runs re-rendered and confirmed unchanged.

**Calibration is enforced in the instrument rather than only written down: a substitution frame must pass `calibratedBy` (an owner attestation naming this record) or the run stamps UNCALIBRATED into its own report, its rendered verdict is styled hedged, and the banner leads with the warning.** Three runs are required for the attestation to be honest, per the verify pass: a positive control, a meaning-preserving placebo, and a length placebo (the verbosity-bias check, which the first two cannot catch, added on the reviewer's argument that "cosmetic" is a human label with no code-enforced length control). Removal-mode calibration buys nothing here.
