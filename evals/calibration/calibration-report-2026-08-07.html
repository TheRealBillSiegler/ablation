Pre-registered decision rules (verbatim)

Click to read the full rules
  • A version wins "NEEDED" for a task when at least two-thirds of the repeats passed WITH the text and at least two-thirds failed WITHOUT it. (per-task flag in the code: degraded = ctrlPass >= ceil(2n/3) && (n - ablPass) >= ceil(2n/3))
  • "DOING HARM" is the mirror image: passes WITHOUT it, fails WITH the text. (per-task flag in the code: harmful = ablPass >= ceil(2n/3) && (n - ctrlPass) >= ceil(2n/3))
  • "NOT NEEDED" requires every task to show no meaningful gap between the two versions. (allNoDelta: every probe has |ctrlPass - ablPass| <= floor(n/3))
  • Any task left with fewer usable repeats than its significance level demands (5 at the standard 0.05 setting; never fewer than 3) makes the whole run INCONCLUSIVE — never guessed around. (lowN = n < max(3, ceil(-log2(alpha))) -> UNRESOLVED)
  • Every paired answer is judged twice with the labels swapped; it counts only if the judge says the same thing both times. Failed workers and disagreeing judgments are thrown out, not scored.
  • The report also shows, per task and overall, how often a gap this big would show up by chance IF the text truly made no difference. It is NOT the chance the verdict is wrong. The number is figured for the direction the data leaned; a reader who did not pick a direction in advance should double it. Evidence strength only; it never decides the verdict. (one-sided exact McNemar sign test on the forced picks: p = P(Binomial(b+c, 0.5) >= max(b,c)))
  • Looking at several tasks gives luck several chances, so the standout task’s fluke chance is also shown corrected for the number of tasks examined. The correction treats tasks as independent — a simplification that errs on the cautious side here, understating significance rather than inflating it. (Sidak: 1 - (1 - min p)^tasks)
  • Each "What this test could have caught" table supposes the text really matters at fixed strengths and shows the chance the run design reaches the bar — never figured from the observed result, because quoting how good a run was at catching the very effect it happened to see would be circular (statisticians call that "observed power").

The verdict cutoffs are screening rules with fixed constants; the fluke-chance numbers (p-values) and 95% ranges are exact statistics reported alongside them (added 2026-08-09) so the strength of each verdict is visible. "NOT NEEDED" means "no difference detected at this sample size" — weaker than proof that the two versions are equivalent. Internal verdict names in the raw data for this report: NEEDED=LOAD-BEARING, DOING HARM=HARMFUL, NOT NEEDED=CEREMONY, INCONCLUSIVE=UNRESOLVED.

Glossary — terms this report uses (hover any dotted term or † mark for its meaning in place)

forced pickA repeat where the blind judges said one version passed and the other failed — consistently, in both label orders. The only repeats that carry direction.
usable repeatA repeat that survived to be scored: the worker produced output and the two blind judgings agreed once the labels were swapped.
workerThe model that performed the task and wrote an answer.
graderThe model that compared a pair of answers, blind, against the pre-registered question.
the barThe significance level (alpha) chosen before the run. A fluke chance at or under the bar counts as statistically clear.
fluke chanceThe p-value: how often a gap this big would show up by chance IF the text truly made no difference. Not the chance the verdict is wrong.
clear winA forced pick favoring the WITH side.
Fine print — applies wherever a † mark appears

†1 — Best-case numbers: the hypothetical assumes every changed repeat lands in favor of the WITH side — the rest tie, none go the other way.

†2 — A fluke chance is NOT the chance the verdict is wrong — it answers "how often would luck alone produce this?", assuming the text changed nothing.

†3 — Fluke chances are one-sided, figured for the direction the data leaned; a reader who did not pick a direction in advance should double them.

†4 — The multiple-looks correction treats tasks as independent — a simplification that errs on the cautious side, understating significance.

†5 — Statistics are reported only; they never decide the verdict. The pre-registered screening rules decide.
